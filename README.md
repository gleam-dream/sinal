# sinal

A strongly-typed take on Erlang :telemetry, built for Gleam's generics instead of dynamic maps and atoms.

Status: design-stage; see [sinal-design.md](https://github.com/gleam-dream/oversight/blob/master/sinal-design.md) in [gleam-dream/oversight](https://github.com/gleam-dream/oversight). Not yet published to Hex.

Ports/wraps: :telemetry (beam-telemetry/telemetry).

## Development

```sh
nix develop
gleam test
```
