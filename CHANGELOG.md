# Changelog

## Unreleased — initial release

- Add BEAM-only typed events and field codecs backed by native `:telemetry` 1.4.2. Handlers receive decoded measurements and metadata synchronously; malformed input or handler failure follows native failure notification and detachment.
- Add explicit attachments, same-shaped multi-event attachments, and scoped subscriptions. Subscriptions acquire sequentially, roll back earlier registrations on failure, and report cleanup failures while retaining successful work results. Catchable exceptions are re-raised with their original class, reason, and stacktrace.
- Add native spans with typed start, stop, and exception descriptors. `run_span_result` retains a completed business result if completion instrumentation cannot be encoded; `run_span` uses a raising policy for encoding failures.
- Add `sinal/forwarder`: a bounded, emitter-side forwarder that hands an event to a dedicated process before any attached handler runs, so a slow or blocked handler stalls the forwarder instead of the producer. `forwarder.emit` never blocks; a send exceeding the configured capacity, or targeting a forwarder that is not currently running, is dropped and reported through `forwarder.dropped_event()` rather than retried. Delivery is best-effort and per-producer FIFO; a handler's `self()` is the forwarder, not the caller; a supervised restart reports and clears whatever was still in flight when the previous incarnation stopped. Additive: `sinal.emit` and `sinal.attach`/`sinal.observe` are unchanged for callers that do not use it.
- Add `fields.optional(key, inner)` so an `Option` field encodes `None` by omitting its key and decodes a missing key, or a raw `nil`/`undefined` marker, as `None`.

The supported target is Erlang/BEAM. The manifest requires Gleam 1.18 or newer and pins `telemetry` 1.4.2; CI exercises Gleam 1.18.1 and OTP 28. JavaScript is unsupported. Delivery is synchronous, handler order is unspecified, detach does not wait for callbacks already running, and uncatchable process termination can bypass scoped cleanup. Export and unbounded buffering are outside this library; `sinal/forwarder` is a narrow, bounded, in-process exception to that, not a substitute for a real buffering or export adapter. The package version remains unchanged until a release decision.
